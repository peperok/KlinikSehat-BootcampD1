# 🏥 Klinik Sehat Bersama - Landing Page

Landing page profil resmi untuk **Klinik Sehat Bersama**, sebuah klinik pratama untuk keluarga yang melayani pemeriksaan umum, kesehatan gigi, dan konsultasi gizi.

Dokumen spesifikasi lengkap, alur pengguna, batasan lingkup, dan arsitektur teknis dapat dilihat di [SPECIFICATION.md](file:///d:/Bootcamp/Day%201%20Offline/SPECIFICATION.md).

---

## 🚀 Fitur & Komponen Halaman

Halaman ini dirancang dalam 1 halaman statis (*Single Page*) dengan 6 *section* utama:
1. **Hero**: Nama klinik, *"Klinik pratama untuk keluarga"*, dan tombol **"Lihat Jadwal"**.
2. **Services**: 4 kartu layanan (Pemeriksaan Umum, Gigi, Gizi, Anak) lengkap dengan durasi dan penjelasan.
3. **Doctor Schedule**: Tabel jadwal dokter yang bersih dan mudah dibaca di ponsel.
4. **Testimonials**: Ulasan pasien dan orang tua untuk membangun kepercayaan (*social proof*).
5. **Pricing**: 3 paket pemeriksaan (Dasar, Keluarga, Lengkap) dengan rincian biaya transparan.
6. **Location & Contact**: Alamat, jam buka loket, tautan Google Maps, telepon, dan WhatsApp.
7. **Footer**: Izin operasional klinik, jam darurat, dan hak cipta.

## 🛠️ Menjalankan Proyek di Lokal

1. **Instalasi Dependensi**:
   ```bash
   npm install
   ```

2. **Menjalankan Server Pengembangan**:
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) di browser.

3. **Membangun Versi Produksi (Siap Netlify)**:
   ```bash
   npm run build
   ```
